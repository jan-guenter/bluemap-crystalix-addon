# Acceptance gallery

Install the datapack, run `function crystalix_gallery:build`, then render the
staging map. `function crystalix_gallery:pose` provides a useful client view.

The disposable gallery occupies `192 99 204` through `250 110 220`. Its seven
groups cover stock controls, all three native forms, persisted RGB, clear and
bordered FULL connectivity, transparent/invisible connection boundaries, and
stable shadeless/light variants. FramedBlocks Crystalix camos are intentionally
deferred because the released FramedBlocks add-on owns that routed namespace.
